Модуль автосервісу для Odoo 17
================================

.. image:: https://img.shields.io/badge/license-LGPL--3-blue.svg
   :target: https://www.gnu.org/licenses/lgpl-3.0.html
   :alt: Ліцензія: LGPL-3

Модуль для управління автосервісним центром у системі Odoo 17. Забезпечує повний цикл обліку ремонтних робіт, клієнтів та транспортних засобів.

Основні можливості
------------------

* Повний облік ремонтних замовлень
* Управління клієнтським автопарком
* База даних автомобільних марок та моделей
* Облік автозапчастин та матеріалів
* Формування звітності

Встановлення
------------

1. Скопіюйте модуль до папки Odoo `addons/`
2. Оновіть список додатків у Odoo
3. Встановіть модуль "Автосервіс"

Налаштування
------------

Після встановлення:

1. Створіть користувачів та призначте їм відповідні групи:
   - Користувач автосервісу (базові права)
   - Менеджер автосервісу (повні права)

2. Налаштуйте категорії послуг та запчастин

Використання
------------

Основні розділи модуля:

* **Замовлення** - створення та супровід ремонтних робіт
* **Транспортні засоби** - облік автомобілів клієнтів
* **Автопарк** - довідник марок та моделей
* **Запчастини** - управління складом комплектуючих

Швидкий старт
-------------

1. Додайте марки та моделі авто у розділі Автопарк
2. Зареєструйте транспортні засоби клієнтів
3. Створюйте замовлення на ремонт з вказівкою:
   - Клієнта
   - Транспортного засобу
   - Переліку робіт
   - Використовуваних запчастин

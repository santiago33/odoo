HR Hospital - Система управління клінікою

Комплексний модуль для управління медичним закладом в системі Odoo.

Основні можливості

  • Управління лікарями - повні профілі, спеціалізації, графіки роботи
  • Реєстратура пацієнтів - медичні картки, історія хвороб, контактні дані
  • Запис на прийом - система планування візитів до лікарів
  • Медичні візити - детальні записи про прийоми, діагнози, призначення
  • Хвороби та діагнози - клінічна база даних захворювань
  • Звіти та аналітика - статистика по пацієнтах, лікарям, захворюванням

Встановлення

  1. Скопіюйте папку модуля до директорії addons вашого Odoo
  2. Перезапустіть сервер Odoo
  3. Увімкніть режим розробника (Налаштування → Інтерфейс → Режим розробника)
  4. Оновіть список додатків (Налаштування → Оновити список додатків)
  5. Встановіть модуль через меню Додатки

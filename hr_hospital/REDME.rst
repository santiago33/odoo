Модуль управління медичним закладом для Odoo

Особливості
-----------
* Повноцінна система обліку пацієнтів
* Управління медичним персоналом (лікарями, медсестрами)
* Система запису на прийом
* Медична карта пацієнта
* Журнал візитів та діагнозів
* База медичних препаратів та призначень
* Звіти та аналітика

Встановлення
------------
1. Додайте модуль до папки addons вашого Odoo
2. Оновіть список додатків (Налаштування → Оновити список додатків)
3. Встановіть модуль через меню Додатки

Використання
------------
Після встановлення:

1. Додайте лікарів у розділі HR → Лікарі
2. Зареєструйте пацієнтів у HR → Пацієнти
3. Користуйтесь системою запису на прийом

Технічні вимоги
---------------
* Odoo 17.0 або новішої версії
* Залежності:
  - hr (модуль персоналу)
  - calendar (для планування візитів)
